前言

在联机过程中，在使用官方直连的情况下，一个群友的网络条件不是很好，而且不想开个加速器会员，因此探索使用局域网软件组网的可能性。

Radmin Lan

可以完美实现局域网的搜索以及加入操作，但是由于中继服务器在国外，延迟巨大。除非你和 Radmin 之间的连接非常优秀，否则不推荐使用。

ZeroTier / Tailscale

延迟同样大，不过可以自建中转服务器达到低延迟的效果，但是这两个软件管理起来不是很方便，在同省同运营商的情况下体验似乎效果很好（未经过详细测试）。并且同样不会自动搜索到房间。

在询问 AI 以及查阅互联网资料后，发现使用 WinIPBroadcast（点击访问源码） 可能使其能自动搜索到房间，但未经过测试，读者可自行探索。

Easytier 的游戏版启动器 也说明了自己已默认启用 WinIPBroadcast，但在我测试的过程之中并不能自动搜索到房间。

原因及参考

我现在正在尝试进行无主之地2的虚拟局域网组网进行联机，我发现在我使用radmin lan的情况下可以搜索到虚拟局域网的房间，但是使用zerotier，tailscale等工具不能搜索到，这是什么原因，如何解决

来自 Google Gemini 的回答：

这是一个非常经典的问题。简单来说，原因在于《无主之地2》（以及许多基于虚幻3引擎的老游戏）在搜索局域网房间时，默认只会向优先级最高或者第一个网络适配器发送广播包。

Radmin LAN 在安装时会自动将自己的网络优先级调得很高，甚至会模拟成一个极其接近物理局域网的环境；而 ZeroTier 和 Tailscale 默认是以“次要适配器”身份运行的，且不支持广播/多播转发（或者默认关闭了相关功能），导致游戏发出的“寻找房间”信号根本没传到虚拟网卡上。

以下是原因分析及解决方案：

核心原因：为什么 Radmin 行，ZeroTier/Tailscale 不行？

  1. 广播（Broadcast）限制：老游戏靠发送 255.255.255.255 的广播包找人。Tailscale 和 ZeroTier 为了节省带宽，默认并不像真实交换机那样转发所有广播。
  2. 网卡优先级（Interface Metric）：Windows 会根据“接口跃点数”决定用哪个网卡上网/发包。Radmin 会强行插队排到第一，而 Tailscale 通常排在后面。游戏找不到房间是因为它往你的物理 Wi-Fi 或以太网卡发广播了，没往虚拟网卡发。
  3. 多宿主（Multi-homed）问题：如果你电脑有多个 IP（物理网卡+虚拟网卡），游戏引擎可能会绑定错误的 IP。

解决方案

方法一：修改启动参数（最推荐，最简单）

你可以强制要求《无主之地2》绑定到虚拟局域网的 IP 上。

  1. 打开 ZeroTier 或 Tailscale，找到你在本网络中的虚拟 IP（例如 192.168.192.x 或 100.x.x.x）。
  2. 在 Steam 中右键点击《无主之地2》 -> 属性 -> 通用 -> 启动选项。
  3. 输入以下命令（将 1.2.3.4 换成你的虚拟 IP）：
    -multihome=1.2.3.4
  4. 主机和客机都建议这么做。这样游戏启动后会强制监听该 IP。

方法二：修改网卡优先级（解决“搜不到”的关键）

让 Windows 认为虚拟网卡是“老大”。

  1. 按下 Win + R，输入 ncpa.cpl 打开网络连接。
  2. 找到你的物理网卡（Wi-Fi 或以太网），右键 -> 属性 -> IPv4 -> 属性 -> 高级。
  3. 取消勾选“自动跃点”，在“接口跃点数”里填入 100。
  4. 找到 ZeroTier 或 Tailscale 的网卡，同样进入高级设置，取消勾选“自动跃点”，将数值改为 1。
  5. 重启电脑。现在游戏发广播时会优先走虚拟网卡。

方法三：ZeroTier 开启广播支持（仅针对 ZeroTier）

如果你使用的是 ZeroTier，需要在网页控制台手动开启：

  1. 登录 ZeroTier Central。
  2. 进入你的网络设置，找到 Members 列表。
  3. 点击成员右侧的那个 🔧（螺手/ wrench）图标或高级设置，确保 Allow Ethernet Bridging (通常不需要，但某些场景有用) 保持默认，关键是检查网络层级是否有阻断广播的设置。
  4. 最简单的方法其实是在控制台顶部的 Settings 确保没有开启奇怪的流量过滤。

总结建议

如果你不想折腾复杂的网络协议，继续用 Radmin LAN 其实是玩这款老游戏最省心的选择，因为它就是专门为“模拟物理二层网络”设计的。

如果你一定要用 Tailscale，请务必配合 方法一（启动参数），因为 Tailscale 是三层网络，默认完全不转发广播，不改启动参数游戏几乎不可能自动搜到房。

写在最后

如果能游戏能手动指定 IP 进行连接就不会有这么多屁事了，你要换成 Minecraft 的话一行 IP 直接就能连了根本用不着花这么多时间😅
